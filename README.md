# Map Your Money
### Exploring global cost of living and purchasing power through data

An interactive Tableau data visualization project analyzing differences in cost of living, income, and purchasing power across countries.

## Project Overview

This project explores how far income goes in different parts of the world by comparing cost-of-living and purchasing-power indicators across countries.

Using international data, we transformed multiple economic indicators into an interactive Tableau story designed to make global affordability differences easier to understand and compare.

## Tools & Skills

- Tableau
- Data Visualization
- Data Analysis
- Data Cleaning
- Data Storytelling
- Exploratory Data Analysis

## Analysis Highlights

The visualization explores:

- Differences in cost of living across countries
- Purchasing power across global markets
- Income and affordability patterns
- Geographic differences in economic conditions
- How multiple economic indicators interact across countries
